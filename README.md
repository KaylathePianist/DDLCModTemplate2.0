# DDLC Minimal Mod Template

The purpose of this template fork is for experienced modders ONLY who need simply a barebones DDLC-related project template, without any "Act 2/3/4" changes (persistent.playthrough), extra menus, poem games, or meta elements/glitches.

If you need a simple template to make a quick mod that doesn't need those features, this is for you :3

An autofocus implementation is included, courtesy of im_just_a_q.

In order to use this, you must use MPT and download the assets for it. This template already has an edited version of the MPT code (to assist with autofocus and such), so do not overwrite any existing files. Just copy over the image assets.

Do NOT use this if you don't use MPT. There are no composite definitions.

Do NOT use this if you want to make a mod that has:
- Meta Elements
- Poems
- Poem Games
- The Console
- Gallery/Achievement Screens
- Multiple Acts
- The Ghost Menu

Do NOT use this if you don't know how to use Ren'Py or mod DDLC.

Also, don't go complain to the original template creators if you're using this one. The file structure is not the same as the other templates.
